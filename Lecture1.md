**Lecture Date:** 04/07/2026

Today's class was the first session of Computer Graphics, and most of it covered the course outline along with a few foundational ideas that will likely come up repeatedly through the semester.

One of the first topics was the difference between lines and curves. It seemed simple at first, but it turned out to be the starting point for most of what this course will build on. A line is the shortest path between two points and can be described with a linear equation, while a curve involves continuous change in direction and requires something beyond a linear equation to describe properly. This distinction seems basic but is clearly foundational.

The question that stood out most was how Computer Graphics differs from Image Processing. These two had felt interchangeable before, but the explanation made the difference clear. Computer Graphics generates an image starting from data or a mathematical model, moving from data toward an image, while Image Processing starts with an existing image and modifies or analyzes it. This difference in direction is an important conceptual point and is worth remembering, since it distinguishes the two fields more clearly than surface-level similarities would suggest.

Geometric primitives came up next, and the answer—lines and curves—connected directly back to the earlier discussion. These two elements are the basic building blocks that more complex shapes eventually break down into.

A newer and less familiar part of the lecture involved graphical frameworks in Java, specifically AWT, Swing, and JavaFX. AWT and Swing are part of the Java runtime, while JavaFX is separate. The distinction between how these frameworks handle rendering and when each is typically used is still not fully clear and remains an area to revisit.

The event listener model was introduced as the design pattern used for building user interfaces. It involves event sources and event firing, and it resembles callback functions seen in other programming contexts. This connection between the two concepts is worth exploring further once concrete examples are introduced in class.

The lecture also raised the question of how curves relate to calculus. This was left open, but it suggests that derivatives or rates of change will be relevant when describing curve behavior in upcoming lectures.

Overall, this first lecture mostly set up vocabulary and framing, particularly around lines and curves and the distinction between Computer Graphics and Image Processing, that later lectures will likely build on directly. The most useful realization from today was that Computer Graphics and Image Processing, despite sounding related, work in fundamentally different directions—one generating images and the other modifying them. This distinction is a good example of why terms that sound similar should not automatically be assumed to be the same.
