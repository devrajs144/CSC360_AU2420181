Lecture Date: 01/07/2026

Today's session kicked off with a discussion around the group project, which felt like a shift from purely lecture-based content into something more applied. As part of this, we set up a GitHub repository for the project and shared access with all team members, which ties directly back to the earlier lectures on Git structure and version control practices, now actually being put into use for a real collaborative setup.

From there, the lecture moved into some mathematical background, covering matrices and systems of linear equations. We went through row vectors and column vectors using an example, which helped make the distinction between the two clearer, since just hearing the definitions without a concrete example probably wouldn't have stuck as well. This also connected to Maven again, but in a different context than before, specifically how certain libraries such as Apache Commons Math, EJML, and ND4J can be used for working with matrices and solving determinants. It was interesting to see Maven come up again here, since earlier it had mostly been discussed in terms of build automation and dependency management, and now it's clear its usefulness extends into supporting actual mathematical computation within Java projects.

We then briefly went over the ongoing projects for group one and group two, which gave a sense of how different teams are approaching their respective builds, though this part of the discussion was fairly short.

An interesting theoretical point came up next, around why a stack is used instead of a queue in a particular context, tied to the concept of erasing. Thinking about how a stack naturally supports undo-style operations because of its last-in-first-out structure made this distinction clearer, since a queue wouldn't support that kind of reversal as naturally.

The lecture then moved into a more applied example involving JavaFX, specifically drawing circles through a right-click action and connecting them using arrows. This tied into a discussion on mouse listeners, since detecting the click and determining where to draw both the circle and the connecting arrows depends on capturing mouse events correctly. This felt like a natural extension of the earlier event listener model discussed much earlier in the course, just applied here in a more visual and interactive context.

Finally, we looked at how to determine whether a given point lies inside a circle, which involved revisiting the distance formula between two points as a kind of proof. Seeing this applied to circles made the earlier coordinate-based work with squares and triangles feel more connected, since checking point containment seems like a natural next step once basic shapes and their coordinates are understood.
